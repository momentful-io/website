Edit Momentful I/O locally

Open the editor, choose Work with Local Repository, and grant access to the project folder containing package.json. You can work without signing in.

Open content editor Preview website README Publishing

Click Save to save locally and check the preview. After saving, press Ctrl+C in the terminal to stop the editor. npm run build builds the site without uploading it.

npm run deploy changes the public website. Set up SFTP or FTPS access and back up the live website first. Saving, previewing, and building are local operations.
